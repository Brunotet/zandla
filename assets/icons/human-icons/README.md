# Human Character Icons Library (297 SVGs)

All four sets below are CC0 1.0 Universal (public domain) — free for
personal and commercial use, no attribution required, verified against
each project's official license page.

## /open-doodles (33 files)
Source: Open Doodles by Pablo Stanley — https://www.opendoodles.com
Full-scene human characters doing activities (dancing, running, reading, etc).

## /open-peeps (144 files)
Source: Open Peeps by Pablo Stanley — https://www.openpeeps.com
Generated via the DiceBear "open-peeps" style — 144 unique seeded characters.
Half-body avatar-style people with varied hair, expressions, accessories.

## /notionists (60 files)
Source: Notionists by Zoish, via DiceBear — https://www.dicebear.com/styles/notionists/
Modern flat-illustration avatar heads, Notion-style, 60 unique seeded variants.

## /lorelei (60 files)
Source: Lorelei by Lisa Wischofsky, via DiceBear — https://www.dicebear.com/styles/lorelei/
Soft, rounded illustrated avatar heads, 60 unique seeded variants.
